# OIBSIP – Web Development Projects

## 📌 About This Repository

Welcome to my **OIBSIP Web Development Projects** repository! This repository contains a collection of web development tasks completed as part of my learning and practical development journey.

These projects demonstrate my skills in building interactive and responsive web interfaces using HTML, CSS, and JavaScript.

## 🚀 Projects Included

### 1. Calculator

A simple, interactive calculator designed to perform basic mathematical operations.

**Features**

* User-friendly calculator interface
* Basic arithmetic operations
* Interactive buttons
* Responsive styling

**Technologies:** HTML, CSS, JavaScript

### 2. Login Authentication

A login and registration interface with a dashboard for demonstrating a user authentication workflow.

**Features**

* Login page
* User registration interface
* Dashboard page
* Styled authentication forms

**Technologies:** HTML, CSS, JavaScript

*Note: A frontend authentication interface does not by itself provide secure, server-side authentication.*

### 3. To-Do App

A task management application designed to help users organize their daily activities.

**Features**

* Add and manage tasks
* Interactive task interface
* Task completion functionality
* Simple and clean design

**Technologies:** HTML, CSS, JavaScript

### 4. Tribute Page

A tribute webpage dedicated to **Marie Curie**, highlighting her life and contributions to science.

**Features**

* Dedicated tribute layout
* Biography and informational content
* Image integration
* Structured and readable design

**Technologies:** HTML, CSS

## 🛠️ Technologies Used

* **HTML5** – Webpage structure
* **CSS3** – Styling and layout
* **JavaScript** – Interactive functionality
* **Git & GitHub** – Version control and project hosting

## 💻 How to Run the Projects

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the downloaded project folder.

3. Navigate to any project directory.

4. Open its `index.html` file in your web browser.

5. Explore the application's interface and functionality.

No additional installation is required for the basic frontend projects.
