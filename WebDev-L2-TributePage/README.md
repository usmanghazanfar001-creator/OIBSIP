# Task 2 — Tribute Page: Marie Curie

A responsive tribute page honouring the physicist and chemist Marie Curie (1867–1934), built with HTML5 and CSS3.

## Features

- Page title containing her name, plus a one-line tagline
- Large portrait image in the header
- Biography section with five original paragraphs
- Timeline of nine key moments, built as an ordered list
- Five achievement cards
- Highlighted quote block
- Responsive layout that adapts to phone, tablet and desktop screens

## Design choices

- **Backgrounds:** dark navy (header and footer), cream (biography and achievements), gold (quote band) and white (timeline)
- **Fonts:** Playfair Display (serif) for headings and the quote, Inter (sans-serif) for body text. Both load from Google Fonts, with Georgia and system fonts as fallbacks.

## Files

| File | Purpose |
|------|---------|
| `tribute.html` | The whole page, with styles included |
| `marie-curie.png` | Portrait image shown in the header |

## How to run

Keep both files in the same folder and open `tribute.html` in a browser. An internet connection is only needed to load the Google Fonts; without it the page still works with fallback fonts.
